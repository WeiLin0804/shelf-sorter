# 貨架整理王

一款輕鬆療癒、帶一點動腦的商品整理遊戲。20 個固定關卡，不限時、不評分，也不需要註冊帳號。

## 開始試玩

試玩網址：https://weilin0804.github.io/shelf-sorter/

支援手機觸控與電腦滑鼠。此為獨立網頁試玩版，尚未正式上架 YouTube Playables。

## 玩法

- 每個貨架最多放三件商品，由右端取放。
- 點來源貨架選取最外側商品，再點目標貨架搬動。
- 只能放到空架，或最外側為同類商品且尚有空位的貨架。
- 將同類商品集中到同一架即可完成整理。
- 再點來源可取消選取，復原與提示不限次數。
- 關卡難度循序變化，中間穿插輕鬆關；沒有倒數或步數評分。

## 進度保存

進度保存在目前瀏覽器，不跨裝置同步。清除網站資料、改用其他瀏覽器或無痕模式，可能無法繼續原進度。請避免同時在多個分頁操作。

## 技術與素材

使用 HTML、CSS 與原生 JavaScript，沒有外部套件或追蹤服務。商品圖示為自製 SVG，音效由瀏覽器產生。程式碼與素材公開供檢視；本儲存庫未另行授予開源授權。
